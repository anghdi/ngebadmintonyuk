# Java Script Feature

## Feed Studio uses Instagram 3:4 portrait
This supersedes the older square Grid Preview note. Feed Studio master panels, exported posts, Seed Row grid cells and Grid Preview use 1080×1440 (3:4). Thumbnails use 432×576, and previews show the full portrait asset without square or 4:5 cropping.
